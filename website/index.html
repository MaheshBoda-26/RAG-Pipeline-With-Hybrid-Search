Core Capabilities

Built for Production RAG

Every component designed for reliability, observability, and scale. No vendor lock-in — runs on your infrastructure.

Hybrid Search

Dense vector embeddings (Qdrant) + sparse BM25 keyword search combined via Reciprocal Rank Fusion. Configurable weights for dense/sparse balance per query.

  • Qdrant embedded or remote
  • BM25 with rank_bm25
  • RRF k=60 default
  • Per-query weight override

LLM Reranking

Batched LLM-as-judge scores top 20 fused candidates in a single call. Falls back to fusion order on parse failure. Costs ~1 call per query.

  • Single batched API call
  • JSON array output
  • Graceful fallback
  • Top-N configurable

Verified Citations

Extract claims → verify against sources → compute composite confidence (retrieval × citation coverage × completeness). Refuses below threshold.

  • Batched verification
  • Composite confidence score
  • Refusal on low confidence
  • Inline citation markers

Smart Chunking

Three strategies: fixed sliding window, recursive markdown-aware, semantic embedding-drift. Switchable via config — no code changes.

  • Fixed / Recursive / Semantic
  • Markdown heading aware
  • Cosine dedup (0.95)
  • Corpus-aware index

REST API + CLI

FastAPI service with Bearer auth. Two endpoints: /v1/ask and /v1/ingest. CLI for local development. OpenAPI docs at /docs.

  • FastAPI + Uvicorn
  • Bearer token auth
  • CLI ingest/ask
  • Auto OpenAPI spec

Eval Ready

Smoke tests with mocked LLM. Golden Q&A dataset structure defined. Chunking strategy comparison via config sweep. Phase 4 extensible.

  • Mocked LLM tests
  • Deterministic embeddings
  • Config sweep ready
  • Golden dataset schema
System Design

Architecture Overview

Modular pipeline with clear stage boundaries. Each component swappable via config — no hard dependencies between stages.

1

Ingestion

loaders.py Multi-format → text
chunking.py Fixed / Recursive / Semantic
dedup.py Cosine > 0.95 skip
2

Retrieval

embeddings.py text-embedding-3-small (1536-dim)
vector_store.py Qdrant dense top-10
sparse.py BM25 top-10
fusion.py RRF k=60
reranker.py LLM judge top-20 → top-5
3

Generation

generate.py Grounded answer + context
citations.py Extract → Verify → Score
prompts.py System prompts & templates

Pipeline Orchestration

class RAGPipeline:
    def __init__(self, settings: Settings):
        self.vector_store = QdrantVectorStore(settings)
        self.sparse_store = BM25Store(settings)
        self.fusion = RRFusion(settings.rrf_k)
        self.reranker = LLMReranker(settings)
        self.generator = GroundedGenerator(settings)
        self.citations = CitationVerifier(settings)

    async def ask(self, question: str) -> Answer:
        dense_hits = await self.vector_store.search(question)
        sparse_hits = await self.sparse_store.search(question)
        fused = self.fusion.combine(dense_hits, sparse_hits)
        reranked = await self.reranker.score(fused)
        answer = await self.generator.generate(question, reranked)
        verified = await self.citations.verify(answer)
        return verified

Get Started

Quickstart

From zero to running RAG pipeline in three commands.

1

Install Dependencies

pip install -r requirements.txt
cp .env.example .env
# Edit .env with your OPENAI_API_KEY
2

Ingest Documents

# CLI
python cli.py ingest ./sample_docs

# Or via API
curl -X POST localhost:8000/v1/ingest \
  -H "Authorization: Bearer dev-secret-key" \
  -H "Content-Type: application/json" \
  -d '{"path": "./sample_docs"}'
3

Ask Questions

# CLI
python cli.py ask "How do I authenticate?"

# Or via API
curl -X POST localhost:8000/v1/ask \
  -H "Authorization: Bearer dev-secret-key" \
  -H "Content-Type: application/json" \
  -d '{"question": "How do I authenticate?"}'
